01Qu'est-ce que la virtualisation ?

La virtualisation consiste à exécuter plusieurs systèmes d'exploitation simultanément sur une seule machine physique, grâce à un logiciel appelé hyperviseur qui partage les ressources matérielles (CPU, RAM, disque) entre des machines virtuelles isolées.

🖥️Host (hôte)

La machine physique réelle et son système d'exploitation principal (ex : Windows 11, macOS, Ubuntu).

📦Guest (invité)

Le système d'exploitation qui tourne à l'intérieur de la VM (ex : Ubuntu, Kali, CentOS).

⚙️Hyperviseur

Le logiciel qui crée et gère les VMs. Il alloue le CPU, la RAM et les disques virtuels.

📀Image ISO

Le fichier d'installation du système invité (équivalent d'un CD/DVD bootable).

04Concepts clés à maîtriser

🧮vCPU

Cœurs CPU virtuels alloués à la VM. Ne jamais dépasser les cœurs physiques de l'hôte.

Recommandé : 2 vCPU

🧠vRAM

Mémoire allouée à la VM, prélevée sur la RAM du host. Ne pas dépasser ~60% du host.

Linux desktop : 2-4 Go

💾Disque virtuel

Fichier (.vdi / .vmdk) qui simule un disque dur. Dynamique = grandit selon l'usage.

VDI · VMDK · VHD

📸Snapshot

État figé de la VM à un instant T : permet de revenir en arrière. Essentiel pour les tests.

Indispensable en cybersec

🌐Mode réseau

Définit comment la VM communique : NAT, Pont, Hôte seul, Interne. À choisir selon l'objectif.

NAT = par défaut

🛠️Guest Additions

Pilotes installés dans le Guest pour le copier-coller, dossier partagé, écran adaptatif.

À installer après l'OS

05Les modes réseau en détail

Le choix du mode réseau détermine quelles communications sont possibles entre la VM, le host et l'extérieur. Choix critique en cybersécurité pour isoler un labo de malware par exemple.

NAT PAR DÉFAUT

La VM accède à Internet via le host (qui fait office de routeur). Elle est invisible depuis le réseau local.

[VM] ──▶ [Host] ──▶ [Internet] ✅ [VM] ◀── [LAN] ❌ [VM₁] ↔ [VM₂] ❌
Usage : tests basiques, navigation web depuis la VM, mises à jour.

Pont (Bridged) RÉSEAU DIRECT

La VM apparaît comme une vraie machine sur le LAN, avec sa propre IP attribuée par le DHCP du réseau.

[VM] ↔ [LAN] ↔ [Internet] ✅ [VM] est visible depuis le LAN ✅ Autres PC peuvent SSH/ping ✅
Usage : serveur web/SSH accessible, services réseau, FTP.

Hôte seul (Host-only) ISOLÉ

Communication uniquement entre host et VM. Aucun accès à Internet ni au LAN.

[VM] ↔ [Host] ✅ [VM] ◀── [Internet] ❌ [VM] ◀── [LAN] ❌
Usage : analyse de malware, lab de pentest isolé, sandbox.

Interne (Internal) VM ↔ VM

Réseau virtuel privé entre les VMs uniquement. Le host lui-même est exclu.

[VM₁] ↔ [VM₂] ↔ [VM₃] ✅ [VM] ◀── [Host] ❌ [VM] ◀── [Internet] ❌
Usage : topologies réseau pédagogiques, simuler un LAN d'entreprise.
